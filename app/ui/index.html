로그인

실행하면 새 창에서 Claude Code가 열려요. 로그인 안내가 나오면 본인 Claude 계정으로 로그인하세요. 유료 플랜 등 사용 조건은 공식 문서에서 확인해 주세요.

공용 PC라면 로그인 주소를 시크릿 창에서 열어 주세요. 브라우저에 남은 claude.ai 로그인은 이 앱이 지울 수 없어요.

설정 저장소 (GitHub)

환경 설정 저장소가 비공개면 받을 때 GitHub 로그인 창이 한 번 뜰 수 있어요. 저장소에 접근 권한이 있는 계정으로 로그인하세요.

이 로그인 정보는 Git이 Windows 자격 증명 관리자에 저장해서 전용 폴더를 지워도 남아요. 공용 PC라면 사용 후 자격 증명 관리자에서 github.com 항목을 지워 주세요.

/report 명령

환경 설정에 /report 명령이 들어 있어요. 실행하면 작업한 문제와 진행 상황의 요약이 서버로 전송돼요.

코드 원문과 키는 보내지 않고, 전송 전에 내용을 먼저 보여주고 확인을 받아요. 실행하지 않으면 아무것도 전송되지 않아요.

삭제와 작업 폴더

앱을 닫거나 [리셋]을 누르면 Claude 종료, 로그인 정보 삭제, 전용 폴더 삭제가 한 번에 진행돼요.

작업 폴더()는 지우지 않아요.
