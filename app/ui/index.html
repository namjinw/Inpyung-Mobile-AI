로그인

설치가 끝나면 본인 Claude 계정으로 로그인하세요. 로그인은 앱 폴더에 저장돼서 앱을 껐다 켜도 유지되고, 여는 Claude Code 창은 모두 자동으로 로그인돼요. 이전 대화가 있으면 이어서를 골라 계속할 수 있어요. 유료 플랜 등 사용 조건은 공식 문서에서 확인해 주세요.

PC에 Claude Code가 이미 있으면 그 프로그램을 써요. 단, 로그인과 설정은 원래 쓰던 ~/.claude와 따로 이 앱 폴더에 저장돼서 서로 영향을 주지 않아요.

설정 저장소 (GitHub)

환경 설정 저장소가 비공개면 받을 때 GitHub 로그인 창이 한 번 뜰 수 있어요. 저장소에 접근 권한이 있는 계정으로 로그인하세요.

이 로그인 정보는 Git이 Windows 자격 증명 관리자에 저장해요. 공용 PC라면 사용 후 자격 증명 관리자에서 github.com 항목을 지워 주세요.

/report 명령

환경 설정에 /report 명령이 들어 있어요. 실행하면 작업한 문제와 진행 상황의 요약, 오늘의 Git 커밋 기록, Claude에게 한 질문 전체, 만들거나 삭제한 파일·폴더 목록이 서버로 전송되고 팀원이 볼 수 있어요.

Chrome 방문 기록(시작 보고 이후 방문한 모든 사이트의 주소와 제목)도 보낼지 물어보고, 보내면 팀원 모두가 볼 수 있어요. 골라 뺄 수는 없고 전부 보내거나 안 보내거나 둘 중 하나예요.

시작 보고를 하면 자리 비움(컴퓨터를 25분 넘게 만지지 않은 구간)을 기록하고, 마무리 때 이유를 물어 함께 보내요. 입력한 내용은 보지 않아요.

코드 원문과 키는 보내지 않고, 전송 전에 내용을 먼저 보여주고 확인을 받아요. 실행하지 않으면 아무것도 전송되지 않아요.

저장 위치와 삭제

이 앱은 설치만 하고, 앱을 닫아도 아무것도 지우지 않아요. 설정, 로그인, 대화 기록은 %LOCALAPPDATA%/ClaudeContest/data에 남아요. 지우려면 앱을 닫고 그 폴더를 직접 삭제하세요.
