모바일 앱 개발 도움 앱

기능경기대회 모바일앱개발 준비를 위해 Claude Code 설치와 팀 설정을 한 번에 해 주는 Windows 앱이에요.

Windows용 다운로드

Windows 10/11 · 64비트 · 버전 내역

이런 걸 해요

1. 환경 점검Windows 버전, 디스크, 인터넷을 확인해요.
2. Claude 설치공식 주소에서 받고 해시를 검증해요.
3. Git 준비없으면 휴대용 Git을 준비해요.
4. 팀 설정 적용적용할 파일을 보여 주고, 확인하면 적용해요.

설치하는 법

  1. 위 다운로드 버튼으로 WordSkill-Setup.exe를 받아요.
  2. 실행해서 설치 위치를 고르고 [설치]를 눌러요. 관리자 권한은 필요 없어요.
  3. 바탕화면의 바로가기로 앱을 열고 [설치]를 눌러 4단계를 마쳐요.
  4. 끝나면 [실행]을 눌러 Claude Code를 시작해요.

처음 실행할 때 Windows가 "PC를 보호했습니다" 창을 띄우면 추가 정보 → 실행을 눌러 주세요. 인증서 서명이 없어서 나오는 안내예요.

쓰는 명령어

  • /report start, /report end 오늘 목표와 작업을 팀 서버에 보고해요.
  • /report-status 보고 서버가 켜져 있는지 확인해요.
  • /ask 이름 라이브러리가 무엇인지 설명과 예제를 알려줘요.

안심하고 쓰세요

  • 설치물과 로그인 정보는 전용 폴더(%LOCALAPPDATA%\ClaudeContest)에만 둬요. 원래 쓰던 Claude 설정은 건드리지 않아요.
  • 앱을 닫거나 [리셋]을 누르면 전용 폴더를 지워요. 앱을 제어판에서 지우기 전에 [리셋]을 먼저 눌러 주세요.
  • 토큰이나 API 키를 저장하거나 입력받지 않아요.
