모바일 앱 개발 도움 앱

기능경기대회 모바일앱개발 준비를 위해 Claude Code 설치와 팀 설정을 한 번에 해 주는 Windows 앱이에요.

Windows용 다운로드

Windows 10/11 · 64비트 · 버전 내역

이런 걸 해요

1. 환경 점검Windows 버전, 디스크, 인터넷을 확인해요.
2. Claude 설치공식 주소에서 받고 해시를 검증해요.
3. Git 준비없으면 휴대용 Git을 준비해요.
4. 팀 설정 적용적용할 파일을 보여 주고, 확인하면 적용해요.

설치하는 법

  1. 위 다운로드 버튼으로 WordSkill-Setup.exe를 받아요.
  2. 실행해서 설치 위치를 고르고 [설치]를 눌러요. 관리자 권한은 필요 없어요.
  3. 바탕화면의 바로가기로 앱을 열고 [설치]를 눌러 4단계를 마쳐요.
  4. 끝나면 [로그인]으로 본인 Claude 계정에 로그인하고, [실행]을 눌러 Claude Code를 시작해요.

처음 실행할 때 Windows가 "PC를 보호했습니다" 창을 띄우면 추가 정보 → 실행을 눌러 주세요. 인증서 서명이 없어서 나오는 안내예요.

쓰는 명령어

  • /report start, /report end 오늘 목표와 작업을 팀 서버에 보고해요. 보내는 것은 아래 "보고할 때 보내는 것"을 확인하세요.
  • /grading 받은 과제지와 채점표대로 에뮬레이터에서 내 제출물을 자동 채점해요. (/grading A처럼 모듈을 고를 수 있어요.)
  • /report-status 보고 서버가 켜져 있는지 확인해요.
  • /ask 이름 라이브러리가 무엇인지 설명과 예제를 알려줘요.

채점에 필요한 것

  • 과제지와 채점표 파일(PDF 권장. HWP는 PDF로 저장해 주세요.)
  • Android SDK와 과제지가 지정한 에뮬레이터, 채점할 APK나 소스 폴더
  • 애니메이션을 확인할 ffmpeg(없으면 설치를 물어봐요), 서버를 쓰는 과제면 켜져 있는 API 서버

AI의 채점 결과는 연습용 참고값이에요. 실제 심사 점수와 다를 수 있어요.

보고할 때 보내는 것

/report를 실행할 때만 보내고, 보내기 전에 내용을 보여 주고 확인을 받아요. 보낸 내용은 팀원 모두가 볼 수 있어요.

  • 작업 요약, 목표 상태, 오늘의 Git 커밋 기록
  • Claude에게 한 질문 전체, 만들거나 삭제하거나 수정한 파일·폴더 경로
  • 자리 비움 시간: /report start 뒤에 컴퓨터를 25분 넘게 만지지 않은 구간과 본인이 고른 이유(무엇을 눌렀는지는 보지 않아요)
  • Chrome 방문 기록: 시작 보고 이후 방문한 모든 사이트의 주소와 제목. 전부 보내거나 안 보내거나 고를 수 있어요.

소스 코드 원문, 파일 내용, .env와 키는 보내지 않아요.

안심하고 쓰세요

  • 설치물과 로그인 정보는 전용 폴더(%LOCALAPPDATA%\ClaudeContest)에만 둬요. 원래 쓰던 Claude 설정은 건드리지 않아요.
  • 앱을 닫아도, 제거해도 전용 폴더는 지워지지 않아요. 설정, 로그인, 대화 기록까지 지우려면 앱을 닫고 %LOCALAPPDATA%ClaudeContest 폴더를 직접 삭제하세요.
  • 토큰이나 API 키를 저장하거나 입력받지 않아요.
